# Fendel Luxury Lumber LLC

Fendel Luxury Lumber LLC, called "Falk" by most employees, is a lumber company that has agriformed at least four planets, including Hylomaru 4, which it turned into a planet-wide tree farm.

## Known Facilities

- Hylomaru 4: planet-wide tree farm in the Finer Goods Production System
- Polar industrial hubs and space elevators: lumber processing and shipping facilities on Hylomaru 4
