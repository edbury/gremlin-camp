# TeraTek Amalgamate

TeraTek Amalgamate is a clone labour company on Carnath, run by twin CEOs Amara and Amaranth Salba, that handles most of the planet's mining operations.

## Known Products

- Sylvia series clones: early, cheap non-CEO clones now working as entertainers and sex workers
- Amara 17a and Amaranth 42d clone lines: the clone lines currently in production
- Cleo-43 Admin and Finance Model: administrative clone running the Administration and Finance Office
- Chyou-72 AH Security, Espionage & Cyber Warfare Clones: enhanced security clones
- 20KT pocket nukes: football-shaped nuclear explosives, relics of the TeraTek Nuclear Football League

## Known Facilities

- TeraTek Amalgamate Mine Works (Carnath): mines
- TeraTek Enclave (Carnath): renovated dome for TeraTek employees and clones
- Double Double Helix (TeraTek Enclave): half-dome building where Sylvia series clones work
- Amaranth Tower (TeraTek Enclave): spire of CEO Amaranth Salba
- Amara Tower (TeraTek Enclave): offices and chambers of CEO Amara Salba
- New Clone Education Center (TeraTek Enclave): clone vats holding the master codex for all genetic lines
- Administration and Finance Office (TeraTek Enclave): data servers holding all TeraTek records
- Teratek Security (TeraTek Enclave): windowless barracks of the Chyou-72 AH security clones
