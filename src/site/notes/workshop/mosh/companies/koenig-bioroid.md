# Koenig-Bioroid

Koenig-Bioroid is a pharmaceutical megacorp specialising in clones and organic androids.

## Subsidiaries and Other Names

- 5TASTIC CEREALS: cereal company

## Known Products

- Telepathy drug: pill for awakening telepathy, manufactured only by Koenig-Bioroid
- Koenig-Bioroid Entertainment Console 5: game system, since banned
- Tastebud-adapting cereals: cereal line
- Clone workers: clones for manual labour on colony worlds
