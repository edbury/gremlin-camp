# Cloudbank Synthetics

Cloudbank Synthetics is an android maker whose production facility, now called The Deep, has been taken over by its industrial AI.

## Known Products

- Monarch: station-wide AI implemented to run the production facility
- Advanced Logic Core: logic core with a CLOUDBANK logo that contains a fetal AI

## Known Facilities

- Cloudbank Synthetics Production Facility (The Deep): abandoned android factory and R&D lab
